## 📚 Overview

This repository contains the complete code, data, and results for the research paper:

> **"Computational Identification of Putative LDHA Inhibitors to Target Metabolic Resistance in Colon Cancer Using Machine Learning and Computer-Aided Drug Discovery (CADD)"**

The study integrates **machine learning**, **molecular docking**, **DFT calculations**, and **ADMET profiling** to identify novel inhibitors of Lactate Dehydrogenase A (LDHA) for colorectal cancer therapy.
